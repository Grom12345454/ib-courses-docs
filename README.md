# Учебник 
## Глава 1. Лучшие практики, стандарты и план действий
Эта глава представляет собой фундаментальное введение в стандарты, фреймворки и лучшие практики кибербезопасности. Цель книги — предоставить менеджерам и специалистам по безопасности всестороннее понимание технологий, операционных процедур и управленческих практик, необходимых для эффективной кибербезопасности.

Книга объединяет документы со стандартами и лучшими практиками в систематический план действий. Хотя эти документы представляют коллективную мудрость многочисленных организаций и экспертов в области безопасности, сами по себе они недостаточны — они сосредоточены на том, **что** нужно сделать, но не содержат учебного материала о том, **как** это сделать.
